# Arisha Raza — Engineering Portfolio

Live site: https://arisharazakhan-cpu.github.io/

Interactive engineering portfolio with four project experiences: PitWall, Smart Jump, Decision Support System, and Cloud Native Backend.

## Editing and publishing

The main site is buildless. Edit `index.html`, `workshop.css`, `workshop.js`, `wireframe.js`, and the project lab files in the repository root. GitHub Pages publishes the root of `main`; `.nojekyll` keeps the static files intact.

`assets/` contains project captures, genuine motion media, and the resume. `pitwall/` contains the bundled static PitWall interface with labeled cached historical data. The original project source is linked from each project experience.

All portfolio simulations run in the browser. Backend previews are local behavioral models, with source and real repository screenshots provided separately. Motion respects reduced-motion preferences and can be paused.
