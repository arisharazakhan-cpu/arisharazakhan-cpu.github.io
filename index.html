WHAT THE PROJECT HANDLES
Not every empty window
means a healthy service.
  • Three explicit outcomes. Passing rules return healthy / 200. Any failure makes the aggregate critical / 503. Missing data without a failure returns degraded / 206.
  • Configurable rules. Thresholds and rolling windows live in the database, alongside products, sources, metric points, and event records.
  • A backend with boundaries. API routing, evaluation logic, ORM models, and persistence remain separate. Alembic manages schema changes.
